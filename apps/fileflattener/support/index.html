How do I export a folder?

Pick a Root Folder and Save Target, choose a preset (or set your own filter rules), then click Scan followed by Flatten & ZIP.

How do exclude filters work?

List patterns to skip — like .git, node_modules, build, *.log — in Filter Rules before scanning. They're excluded from both the file tree and the exported ZIP.

Is there a size limit?

Yes — FileFlattener enforces a safe ceiling on scan/export size to prevent accidental oversized exports.

What are the Folder Graph / Code Graph / Call Graph tabs?

Visual views generated from your scan — folder structure, detected classes/functions (for recognized project types), and call relationships.

Where are my settings stored?

Locally, in the Windows registry under HKEY_CURRENT_USER\Software\FileFlattener — just your 5 most recent folder paths and UI preferences. See the privacy policy.

How do I fully remove FileFlattener and its settings?

Uninstall the app, then remove the HKEY_CURRENT_USER\Software\FileFlattener registry key if you want to clear its saved preferences too.
